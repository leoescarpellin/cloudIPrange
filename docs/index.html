Firewall Quick-Start Integration

pfSense (URL Table Aliases)

  1. In pfSense WebGUI, navigate to Firewall → Aliases → IP and click Add.
  2. Configure the alias:
    • Name: Azure_Storage_IPv4 (or any descriptive identifier).
    • Type: Select URL Table (IPs).
    • URL: https://leoescarpellin.github.io/azureIPranges/ranges-services/AzureStorage.ipv4.txt (or a regional list like .../ranges-regions/brazilsouth.ipv4.txt).
    • Update Frequency: Enter 1 day (or 7 days).
  3. Click Save and Apply Changes. pfSense will fetch and load the CIDRs into packet filter (pf).
  4. In Firewall → Rules, select the alias as the Source or Destination.
Best Practice: Always use .ipv4.txt for IPv4 rules and .ipv6.txt for IPv6 rules. pfSense produces an error if IPv6 addresses are present inside an alias assigned to an IPv4 rule.

OPNsense (URL Table Aliases)

  1. In OPNsense WebGUI, navigate to Firewall → Aliases and click + (Add).
  2. Configure the alias:
    • Enabled: Checked.
    • Name: Azure_BrazilSouth
    • Type: URL Table (IPs)
    • Content: https://leoescarpellin.github.io/azureIPranges/ranges-regions/brazilsouth.ipv4.txt
    • Refresh Frequency: 1 (days).
  3. Click Save and Apply. OPNsense creates an in-memory pf table automatically refreshed by cron.
  4. Reference the alias in your firewall rules under Firewall → Rules.
Inspection: You can verify active loaded addresses at any time in Diagnostics → Tables.

Palo Alto Networks (External Dynamic Lists - EDL)

  1. In PAN-OS WebGUI, go to Objects → External Dynamic Lists and click Add.
  2. Set Name (e.g., EDL-Azure-Storage) and Type to IP List.
  3. In the Source tab:
    • Source URL: https://leoescarpellin.github.io/azureIPranges/ranges-services/AzureStorage.txt (or .ipv4.txt).
    • Repeat: Select Daily or Weekly.
  4. Click Test Source URL to confirm connectivity and verify the list count.
  5. Commit changes and use the EDL object in Policies → Security as Source or Destination address.
EDL Capacity: Deduplication is already performed across all lists, preserving maximum capacity under your firewall's EDL license limit.

MikroTik RouterOS (Address Lists & Script)

  1. In WinBox or Terminal, create a scheduled script under System → Scripts: 
    /tool fetch url="https://leoescarpellin.github.io/azureIPranges/ranges-regions/brazilsouth.ipv4.txt" dst-path="azure_brazil.txt"
:local content [/file get azure_brazil.txt contents]
:local lineEnd 0
:local line ""
/ip firewall address-list remove [find list="Azure_Brazil"]
:while ([:len $content] > 0) do={
    :set lineEnd [:find $content "\n"]
    :if ([:len $lineEnd] = 0) do={ :set lineEnd [:len $content] }
    :set line [:pick $content 0 $lineEnd]
    :set content [:pick $content ($lineEnd + 1) [:len $content]]
    :if ([:len $line] > 0) do={
        /ip firewall address-list add list="Azure_Brazil" address=$line timeout=1d
    }
}
/file remove azure_brazil.txt
  2. Add a task in System → Scheduler to run the script once every 24 hours.
  3. Use the Azure_Brazil Address List in /ip firewall filter or /ip firewall nat rules.

Fortinet FortiGate (External Threat Feeds)

  1. In FortiOS WebGUI, navigate to Security Fabric → Fabric Connectors (or External Connectors).
  2. Click Create New and select Threat Feeds → IP Address.
  3. Configure the connector:
    • Name: Azure_Storage_Feed
    • URL: https://leoescarpellin.github.io/azureIPranges/ranges-services/AzureStorage.ipv4.txt
    • Refresh Rate: Daily (or every 1440 minutes).
  4. Click OK and verify status shows green with entry count.
  5. Use the Threat Feed object as a Source or Destination Address in Policy & Objects → Firewall Policy.

Cisco Firepower / ASA (Dynamic Objects)

  1. In Firepower Management Center (FMC), navigate to Objects → Object Management → Security Intelligence → Network Lists and Feeds.
  2. Click Add Network Lists and Feeds:
    • Name: Azure_Services_Feed
    • Type: Feed
    • Feed URL: https://leoescarpellin.github.io/azureIPranges/ranges-services/AzureStorage.ipv4.txt
    • Update Frequency: Daily
  3. Save and Deploy configuration to your FTD devices.
  4. On Cisco ASA (CLI), you can automate periodic population of object-group network via Python or EEM scripts.
